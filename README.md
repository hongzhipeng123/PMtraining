# AI PM 修炼场

一个**系统化的 PM 成长平台**，集知识学习、AI 辅助工具、名词速查、面试陪练于一身。采用深色科技风设计，整合 DeepSeek 大模型能力，帮助产品经理从入门到精通。

## ✨ 核心功能

### 🧠 知识图谱
- **8 大能力域**：产品策略、用户研究、需求管理、数据分析、技术理解、项目管理、AI产品、商业化
- **48 个知识点**：每个都配备详尽解释（500-800 字）+ AI 深度讲解
- **思维导图展示**：可视化节点连线，支持缩放和拖拽

### 🤖 AI 工具箱
三个企业级 AI 工具，支持流式输出和 Markdown 渲染：

1. **市场调研助手**
   - 输入产品方向 → AI 生成 12 章节完整市场调研报告
   - 包含市场规模、竞争格局、用户需求、技术趋势等

2. **竞品分析器**
   - 输入竞品名称或赛道 → 6 维度对标分析
   - 支持多个竞品同步对比

3. **PRD 生成器**
   - 输入需求描述 → 生成完整产品需求文档
   - 含产品概述、核心功能、用户流程、验收标准等

### 📚 名词百科
- **39 条 PM 核心术语**：涵盖产品基础、数据指标、技术概念、商业模式等 9 个分类
- **智能搜索**：支持术语名、英文缩写、定义内容搜索
- **生词本功能**：收藏重点术语，支持筛选查看
- **AI 大白话解释**：通俗易懂 + 类比理解 + 实战应用

### 🎤 模拟面试官
- **28 道精选面试题**：覆盖 6+ PM 必考领域
- **多轮对话 AI 面试**：前 3 轮追问，第 4 轮输出专业点评
- **智能评分体系**：优点、改进点、参考框架三维反馈
- **换题重试**：支持无限练习

### 📅 每日一问
- **365 日循环题库**：每天一道新题，定时刷新
- **AI 智能评分**：提交答案后获得分数 + 详细解析
- **每日仅一次**：防沉迷设计，鼓励深度思考

### 📊 成长仪表盘
- **实时数据统计**：知识/工具/词典/面试四维追踪
- **能力雷达图**：可视化展示个人 PM 能力模型
- **7 个成就勋章**：
  - 初入江湖（首次登录）
  - 工具达人（首次使用 AI 工具）
  - 求知若渴（收藏 5 个生词）
  - 面霸初成（完成 3 次模拟面试）
  - 持之以恒（连续 7 天每日一问）
  - 全知全能（浏览全部知识节点）
  - 效率大师（累计使用 AI 工具 10 次）
- **学习轨迹**：自动记录所有学习行为

## 🚀 快速开始

### 1. 本地运行

**方式一：VS Code + Live Server**
- 用 VS Code 打开项目文件夹
- 安装插件 Live Server
- 右键 `index.html` → Open with Live Server

**方式二：Python**
```bash
cd ai-pm-arena
python3 -m http.server 8080
# 访问 http://localhost:8080
```

**方式三：Node.js**
```bash
npx serve ai-pm-arena
```

### 2. 首次使用
1. **注册账号**：输入用户名和密码
2. **配置 API Key**（可选）：
   - 点左下角「设置」
   - 填入 DeepSeek API Key
   - 点「测试连接」验证
3. **开始学习**：浏览知识图谱、查阅百科、使用工具

> 💡 不配置 API Key 也能用！知识图谱和百科有完整的静态内容，只有 AI 生成功能需要 API。

## 🔧 技术栈

- **前端框架**：React 18.3.1（通过 CDN 引入）
- **AI 引擎**：DeepSeek API（流式调用）
- **渲染**：marked.js（Markdown 解析）
- **存储**：浏览器 LocalStorage（用户隔离）
- **设计**：深色科技风 + 紫色渐变配色

## 📱 移动端适配

整套平台已适配手机浏览器，**且不影响电脑端体验**（断点 `≤768px`）：

- **汉堡抽屉导航**：顶部栏汉堡键唤起左滑抽屉 + 遮罩，点导航自动收起
- **底部上滑面板**：设置、知识点/词条详情改为 bottom sheet
- **知识图谱**：手机端切换为可折叠列表视图（桌面端仍是思维导图，数据互通）
- **栅格自适应**：多列卡片在手机上降级为单列 / 双列
- **聊天体验**：面试 chat 输入框吸底、适配键盘安全区
- **输入框 16px**：避免 iOS 聚焦自动缩放；适配刘海屏安全区

## 💾 数据持久化

所有数据存储在浏览器本地（localStorage / sessionStorage），格式：
- `pm_users`：用户注册信息
- `user_{username}_apikey`：API Key
- `user_{username}_stats`：使用统计
- `user_{username}_track`：学习轨迹
- `user_{username}_achievements`：解锁成就
- `user_{username}_vocab_saved`：收藏词汇

> 🔒 API Key 只在本地存储，永不上传到服务器
>
> 📱 **纯本地、不跨设备同步**：手机与电脑、不同浏览器之间数据互不相通；登录态存于 sessionStorage（关标签页即清空，需重新登录）。跨设备迁移请用「设置 → 数据管理 → 导出/导入 JSON」。清理浏览器数据会清空全部记录。
